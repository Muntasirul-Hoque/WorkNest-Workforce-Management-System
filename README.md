# WorkNest — Workforce Management System

**A Web-Based Employee Management System for Modern Workplaces**

WorkNest is a web-based workforce management application developed as part of the Web Technologies course at the American International University-Bangladesh (AIUB). The project aims to simplify employee management, streamline workplace workflows, and provide role-based access to essential workforce operations through a centralized platform.

## Overview

Managing employees, assigning tasks, handling leave requests, and maintaining employee records can become complicated when these activities are handled manually. WorkNest aims to bring these operations together in one accessible web application.

The system provides separate interfaces for administrators, managers, and employees, allowing each role to access the functions relevant to its responsibilities.

## Key Features

- **Role-Based Access:** Separate portals for HR/administrators, managers, and employees.
- **Employee Management:** Manage employee information and workforce records.
- **Task Management:** Assign tasks and track their progress.
- **Leave Management:** Submit, review, and process employee leave requests.
- **Promotion Requests:** Support promotion-related requests and administrative review.
- **Employee Lifecycle Management:** Support employee recruitment, promotion, and termination workflows.
- **Authentication:** Login, password recovery, and logout functionality.
- **Dashboard Interface:** Organize role-specific information and actions in a centralized interface.

## User Roles

| Role                   | Responsibilities                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------------- |
| **HR / Administrator** | Manage employee records, oversee workforce operations, and process administrative requests. |
| **Manager**            | Manage team activities, assign tasks, review requests, and track employee progress.         |
| **Employee**           | Access the employee portal, view assigned tasks, update progress, and submit requests.      |
